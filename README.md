# 調査員ジャーナル — Phasmophobia ゴースト特定ツール

証拠・ハント正気度・移動速度からゴーストを絞り込む静的Webアプリ。フレームワーク不要、素のHTML/CSS/JSのみ。スマホ対応。

## ファイル構成

```
index.html        UIの骨組み
style.css          見た目
app.js             フィルタリングロジック（状態管理・描画）
data/ghosts.json   ゴーストデータ本体（証拠・正気度・速度）
```

## 操作方法

- **証拠**: タップするたびに 未選択 → ✓確定 → ✕除外 → 未選択 と切り替わる
- **ハント時の正気度 / 足の速さ**: 「低い/普通/高い」などのボタンを選ぶ（もう一度押すと解除）
- 該当ゴーストが下のジャーナルにリアルタイムで絞り込まれる

# GitHubに公開するまで（超初心者向け・ゼロから）

ターミナルやgitコマンドは一切使わず、**ブラウザの操作だけ**で完結する方法で説明します。

## ステップ1: GitHubアカウントを作る

1. https://github.com/ にアクセス
2. 右上の **Sign up** をクリック
3. メールアドレス・パスワード・ユーザー名を入力して指示に従って登録
4. メール認証を済ませる

すでにアカウントがあればこのステップは飛ばしてOKです。

## ステップ2: 新しいリポジトリ（保管庫）を作る

1. ログイン後、右上の **＋** ボタン → **New repository** をクリック
2. **Repository name** に好きな名前を入力（例: `phasmo-ghost-finder`）
   - 半角英数字とハイフンのみ推奨
3. **Public** を選択（GitHub Pagesを無料で使うにはPublicが必要）
4. 「Add a README file」などのチェックは**入れなくてOK**（このあとまとめてアップロードするため）
5. **Create repository** をクリック

これでリポジトリが作成され、空っぽの画面が表示されます。

## ステップ3: ファイルをアップロードする

1. リポジトリのページで **Add file** → **Upload files** をクリック
2. このツールのフォルダの中身（`index.html`, `style.css`, `app.js`, `data`フォルダ, `README.md`）を
   **フォルダごとではなく中身を全部選択して**ドラッグ＆ドロップ
   - `data` フォルダごとドラッグすれば `data/ghosts.json` として正しく認識されます
   - 迷ったら、ダウンロードしたzipを一度解凍し、その中身を丸ごとドラッグしてください
3. 下にスクロールして **Commit changes** をクリック（コメント欄は空のままでOK）

アップロードが終わると、リポジトリのトップページにファイル一覧が表示されます。

## ステップ4: GitHub Pagesを有効にする

1. リポジトリ画面の上部タブから **Settings** をクリック
2. 左メニューの **Pages** をクリック
3. **Build and deployment** の **Source** を `Deploy from a branch` に設定
4. **Branch** を `main` / フォルダを `/ (root)` に設定して **Save**
5. 1〜2分待ってからページを再読み込みすると、画面上部に

   > Your site is live at `https://<あなたのユーザー名>.github.io/<リポジトリ名>/`

   というURLが表示されます。これが公開URLです。

## ステップ5: 動作確認

表示されたURLにスマホ・PCどちらからでもアクセスして、証拠ボタンやハント正気度ボタンを押して候補が絞り込まれるか確認してください。

## データを更新したいとき（新しいゴーストの追加やアプデ対応）

コードは一切いじらず、**`data/ghosts.json` を編集するだけ**でOKです。

1. GitHubのリポジトリ画面で `data/ghosts.json` を開く
2. 右上の鉛筆アイコン（Edit this file）をクリック
3. 中身を書き換える（1体分の構造は下記）
4. 下にスクロールして **Commit changes** をクリック
5. 数十秒〜数分後に公開サイトへ自動反映される

1ゴーストの構造:

```json
{
  "id": "spirit",
  "ja": "スピリット",
  "en": "Spirit",
  "evidence": ["emf5", "spiritbox", "writing"],
  "huntSanity": 50,
  "sanityNote": "補足があれば書く（空文字でも可）",
  "speedMin": 1.7,
  "speedMax": 1.7,
  "tips": "識別のヒントや特殊挙動"
}
```

- `evidence` は必ず3つ（`emf5` / `spiritbox` / `uv` / `orbs` / `writing` / `freezing` / `dots` のいずれか）
- 速度が一定なら `speedMin` と `speedMax` を同じ値にする
- 新しいゴーストが追加されたら配列に1件追加するだけでUI・フィルタ両方に自動反映される

**投入済みのデータはWiki・攻略記事ベースの目安です。** 特に新しめのゴースト（ダヤン・ガルル・オバンボ・アスワング・コルモス・デイルデガストなど）は数値が公式に完全開示されていないものも多いので、実戦で気づいた誤りはどんどん書き換えて自分のパーティ専用のデータベースに育ててください。

## ローカルで動作確認したい場合（任意・上級者向け）

`fetch('data/ghosts.json')` を使っているため、`index.html` を直接ダブルクリックでは動きません。

```bash
# このフォルダで実行
python3 -m http.server 8000
# → http://localhost:8000 にアクセス
```
